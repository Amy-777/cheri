First time install

  1. Tap Download the app above (open this page in Chrome).
  2. When it finishes, tap Open on the download message.
  3. If Android says "For your security, your phone isn't allowed to install unknown apps from this source", tap Settings and switch on Allow from this source, then press back.
  4. Tap Install, then Open.

Updating to a new version

  1. Open this same page again and download the app.
  2. Install it over the old one. Do not uninstall first. Your login and data stay.

If it does not install

If it says "App not installed", uninstall the old copy once and install again. Still stuck? Message us and we will help.
